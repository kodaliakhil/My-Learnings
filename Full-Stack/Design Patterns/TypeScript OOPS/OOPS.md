# Object Oriented Programming
- OOP is a programming paradigm that uses the concept of objects as a way to structure and organize code.
- It helps developers to build more flexible, reusable and maintainable software.
- There are 4 main concepts in OOP. They are:
    1. `Abstraction`
    2. `Encapsulation`
    3. `Inheritance`
    4. `Polymorphism`
